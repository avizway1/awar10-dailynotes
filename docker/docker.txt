Monolithic architecture : in monolithic architecture all software components are going to be bound together into a single unified codebase. 
--> All or nothing, as a monolithic architecture deployed as one single unit.
--> We can choose only one programming language to develop the entire application.
--> If we have to scale we need to scale the entire application. We cannot scale only one feature. 
--> In most cases we will have a centralised database for the entire application. 

Microservices architecture: In general, microservice architecture is designed to break the entire application into smaller independent services that can communicate with each other to deliver the application. 
--> Each service is completely independent. 
--> We can scale services independently (more servers : frontend, less servers: payment)
--> It's polyglot. We can choose the required or best programming languages per module.
- For the frontend : Java
- For rating : PostgreSQL database.
- For user management : MySQL.
- For recommendations : Python.

Bridge Mode: 
1. Bridge mode will have its own IP addresses inside the Docker network.
2. We can perform the port mapping to deliver the application.
3. This is more isolated and secure. Your container won't be directly exposed to the network.
4. This mode has a net component that helps to resolve the container IP addresses, so one additional hop is involved in the traffic flow.
5. This is best for enterprise-grade and multi-container applications.
6. This works on Linux, macOS, and Windows operating systems.

Host Mode: 
1. It shares the host IP address and port.
2. Port mapping is not required. It directly uses the host IP address and port.
3. Less isolated compared to bridge as it is directly exposed over the host network.
4. Slightly faster compared to bridge as this has one hop less.
5. We can use this specifically for a monitoring agent not to run over a regular workload.
6. Works only on the Linux operating system.

docker run -d --name host-test --network host nginx:latest
docker run -d --name host-test2 --network host nginx:latest
