git it is a version control system. It is a tool that records snapshots, meaning changes to our project over time, so we can review history. If we make any mistake we can undo it and we can collaborate with all other team members without overwriting each other's work. 


1973	- SCCM - Source code control system - 1 file
		  RCS - Revision control system 	- x files, 1 Directory
		  CVS - Cuncurrent vesion system	- x file, x folders, 1 user
2000	- SVN - Subversion					- x files, x folders, x users
2005 	- GIT - Global Infroamtion Tracker	- x files, x folders, x users, branching, cherrypick..

objects/		: Directory structures, File content in blobs, Commit histories, Tags stored here
refs/			: stores pointers to commits
hooks/			: It contains customizable scripts that get run automatically before or after commit or push operations. 
logs/			: Keeps the history of changes that are happening on our repo.

HEAD			: This points to the latest or current checkout branch or specific commit hash.
