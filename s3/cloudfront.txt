Amazon SQS : Simple Queue Service : 


Standard: Atleast-once delivery mechanism.. Message order wont be preserved.
--> Best effort ordering
--> At-least once delivery

FIFO : First-in and First-out delivery.. Message order will be preserved.
--> First-in and First-out
--> Eaxctly once processing

DLQ / Deal letter Queue : A dedicated queue designed to store undelivered messages.

Max Msg retention period: 14 Days
Maximum message size: 1024 KiB

--> Service Decoupling
--> ratelimiting
--> Independent Scalability

SQS is a poll based msg servcie. 

poll : The consumer actively asks the provider for new data at regular intervals. 
push : The provider automatically sends data to the consumer periodically.
