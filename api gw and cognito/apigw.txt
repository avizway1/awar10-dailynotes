


Cognito: A fully managed identity management service. This service helps to add user sign-up, sign-in and access control to web and mobile applications.
--> This eliminates complex backend logic building.

UserPool: Act as user directories. It uses JWT Token for authetication (JSON Web Token - JWT).

1. Authentication : Uses AWS generated Web UI.
2. Token generation : The user pool validates the credentials and returns the JWT token.
3. Authorization : Talking to application using token
4. Access: provides the service access.
