Cloudtrail : Track User Activity and API Usage

--> Enabled by default, It can store last 90 days activities.
--> We can store all longs into an s3 bucket or cloudwatch logs group. We can configure retention period based on our requirement.
--> COnfigure s3 life cycle manaegement rule and setup retention period.
--> CLoudwatch logs also has retention period on logs group.
--> Cloudtrail suports multiAWS Acocunts. We can store all aws account logs into single Aws account's s3 bucket (central logging account).
--> 1 x Management trail is free. 

We have 4 types of trails: 

1. Management trail : Designed for aws management console operation logging (Bucket create / instance launch / rds create)
2. Data Trail : S3, Lambda, dynamoDB... We can enable to log data level operations.. (current and future resource)
3. Insight Events : Helps to identify unuseual activities, errors or user behaviours.. 
4. Network Trails : network flow events.. 

--> We can create a trail and store data into s3/cw for unlimited days.
--> If the AWS service is GLOBAL Service.. make sure to look for logs in "N. Virginia" region.
